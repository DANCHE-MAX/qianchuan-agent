利润测算对比

ⓘ 怎么看

对比同一天按不同计算方式估算的利润。差额＝当前口径测算－原日报利润。

这是计算方式带来的差异，不是实际多赚或少赚；不会改写历史报表。

“取值依据”说明退款率用了哪个已确认价格档；未匹配档位时采用总体率，不是当天实际退款率。

左侧为原日报值或明确标注的未发送复核值；右侧为当前口径测算，不改写原报表。对照测算仅使用同一天的数据。
