# 演示数据说明

[返回项目首页](../README.md)

全部为虚构演示数据，不是真实经营结果、截图或发送记录，不读取本地运行配置。生成脚本为`scripts/refresh_demo_consistency.py`，只写文档演示SVG，不修改运行程序。

## 发送顺序

简短日期提示＋一次@投手（虚构示意）→每日三件事导读图→利润图（所有分页）→Excel附件→两日消耗图→四宫格。接收流程图直接嵌入同一组独立SVG；Excel为附件占位示意，不链接真实报表。余额图为独立时段提醒，不混入日报发送流程。

## 独立余额演示

余额图使用另一组虚构时段数据：蓝=本两小时120元/小时、橙=前两小时80元/小时、紫=昨日同段100元/小时，可用余额1,200元，按本期速率估算10小时。余额净下降不等于广告消耗；这些颜色不代表商品。
